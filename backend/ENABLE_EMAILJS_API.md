# 🔧 Enable EmailJS Server-Side API Access

## ❌ Current Error

**"API calls are disabled for non-browser applications"**

EmailJS has server-side API calls disabled for your account.

---

## ✅ Solution: Enable API Access

### Step 1: Go to EmailJS Dashboard

1. **Login**: https://www.emailjs.com/
2. **Click "Account"** (top right or left sidebar)
3. **Click "General"** or **"Settings"**

### Step 2: Enable Server-Side API

Look for one of these options:

**Option A: API Access Setting**
- Find **"API Access"** or **"Server-side API"**
- **Enable** or **Turn ON** "Allow server-side API calls"
- **Save** changes

**Option B: Security Settings**
- Go to **"Security"** or **"API Settings"**
- Find **"Restrict API to browser only"**
- **Turn OFF** this option
- **Save** changes

**Option C: Account Settings**
- Look for **"Allow non-browser API calls"**
- **Enable** this option
- **Save** changes

### Step 3: Wait & Test

1. **Wait 1-2 minutes** for changes to take effect
2. **Restart your server**
3. **Test email sending again**
